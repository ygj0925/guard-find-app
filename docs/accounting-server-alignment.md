# App 与记账服务同步说明

本次对照 `guard-find-server` 的 `/app/ledger`、`/app/ledger/group` 和 `/app/accounting` 控制器与响应模型完成同步。

## 已接入的界面行为

- 创建流水返回值使用字符串 ID，创建与编辑请求显式携带目标家庭组。
- 家庭组成员可以查看共享记录，仅记录作者可以进入编辑或删除流程；服务端继续执行最终权限校验。
- 记一笔页面固定本次选择的目标账本，识别草稿不会因返回或切换账本被静默记入其他组。
- CSV 导出与当前账本一致；超过5000条明确提示，不输出截断后冒充完整的文件。
- 月度总额使用服务端汇总，不再把已加载的第一页当作整月金额。切换月份、家庭组或账号会丢弃旧请求结果。
- 家庭组组长可以在成员行移交组长，确认提示说明身份和邀请码变更，成功后刷新成员和组权限。
- 记账首页进入“票据管理 · 文字/图片识别”：上传图片、查看/删除个人票据，识别文字或已上传票据。识别结果必须先填入记一笔表单、核对并保存才会入账。
- 私有票据下载通过带会话头的请求处理二进制，不把鉴权令牌拼进链接；JSON鉴权失败仍交给统一401处理。
- 账本选择按用户独立保存；不自动沿用无法确认归属的旧设备级选择记录。重新选择一次即可保存到新键。

## 新增服务适配层与范围

`lib/api/endpoints/accounting.ts` 提供快照GET/PUT/PATCH、票据列表/上传/下载/删除、识别和语音转写接口。快照请求保留 `baseVersion`、`operationId`、`knownVersion` 和实体变更；4002冲突直接向上抛出，不自动覆盖或换新操作ID重试。

服务端的 `jianzhang` 快照包含资产、分类、标签、周期和设置，是独立数据模型。本 App 现有流水使用 `/app/ledger`，没有将两者互相转换，也没有把当前流水页面标为简账快照同步。快照接口适配已经就绪，完整的简账本地模型和冲突合并界面仍需要单独实现。

票据支持JPEG/PNG/WebP/PDF，服务端限制单张5MB、个人总空间100MB；当前页面使用既有图片选择能力上传图片。PDF上传及语音转写提供服务适配，未新增PDF文件选择器或原生录音依赖。设备不支持既有图片选择能力时明确提示，并保留文字录入。

AI识别依赖服务端 `guardfind.accounting.ai` 的开关、供应商、模型及密钥；缺少配置时展示实际服务端错误，不返回假结果。识别及转写超时75秒，为服务端60秒调用留出传输时间。密钥不进入App。

## 验证

自动测试覆盖服务契约、字符串ID、家庭组作用域、整月汇总、账号隔离、快照冲突直传、上传约束、私有下载的401、识别待确认和未启用提示。未调用真实识别供应商，未执行生产迁移；原生选图和完整联调需在已配置服务端及对应设备上验证。

本次验证：App全量40个测试套件、323项测试通过；TypeScript类型检查及本次变更业务文件的ESLint检查通过。测试中的原生模块使用显式虚拟mock，允许在未安装原生运行模块的测试环境中验证能力降级。
